전체 개요

이 워크스페이스는 인스타 DM 영업부터 공동구매 진행까지 한 곳에서 처리합니다.

  • 인플루언서 5,000명 DB — 엑셀로 일괄 임포트
  • 100+ 인스타 계정 풀 — 기기별 그룹 + 회신율 정량 추적
  • 자동 발송 큐 — 차수 ≤10 / 7일 간격 / 매번 다른 계정 강제
  • 통합 인박스 — 100계정의 모든 답장을 한 화면에
  • 메타 광고관리자 스타일 캠페인 — 캠페인 > 세트 > 공동구매
URL
• 사용자 PC: http://127.0.0.1:5000 — Playwright DM 발송/답장 동기화 가능
• 클라우드: https://nextport-workspace.onrender.com — 데이터 조회/편집만 (발송 불가)

셀러 캠페인

데일리 DM 관리

1. 통계 카드

  • 발송 후보 — 오늘 보낼 수 있는 인플루언서 수 (규칙 통과한 수)
  • 활성 계정 — 상태=활성 인 계정 수
  • 오늘 발송됨 — 오늘 날짜로 발송된 건수
  • 답장 도착 — 누적 답장 받은 conversation 수

2. 발송 멘트 + 양식 회신율

  • 템플릿 선택: 미리 박아둔 템플릿 선택 (한 번 박으면 통계 누적)
  • 직접 멘트 입력: 비워두면 위 템플릿 사용 / 박으면 그 멘트 사용 (통계 X)
  • 양식별 회신율: 발송 수 대비 답장 받은 수 자동 계산 → 효과 좋은 멘트 추적

3. 오늘 보낼 큐

  • 큐 재계산: 현재 인플루언서/계정 데이터로 후보 재산출
  • 전체 발송 시작: 체크된 모든 큐 순차 발송 (사이 30~120초 랜덤 대기)
  • 개별 발송: 한 행씩 즉시 발송
  • 제외 사유: 통과/상태제외/10차도달/7일미경과/계정없음 통계 표시

DM 발송 (실시간)

  • 현재 상태: 발송 중인 작업 카드 (계정 → 셀러 + 차수 + 경과시간)
  • 발송 로그: 콘솔 스타일 실시간 스트림 (start / done / fail)
  • 비우기: 로그 클리어
  • CSV: 로그 다운로드
클라우드 제약
Render 클라우드에서는 Playwright 브라우저를 못 띄움 → 실제 발송은 사용자 PC에서만 동작.

DM (수신) — 통합 인박스

  • 좌측: 셀러별 대화 리스트 (안 읽은 건 빨간 배지)
  • 우측: 메시지 thread (인스타식 말풍선)
  • 답장 동기화: 모든 활성 계정에서 받은 DM 한 번에 동기화 (~10초/계정)
  • 답장 입력: 그 대화의 우리 계정으로 자동 발송
  • 알람: 새 답장 오면 우상단 toast — 클릭 시 그 대화 자동 열기

전체 인플루언서 DB

1. 엑셀 임포트

  • 양식 다운로드: 17컬럼 헤더 + 예시
  • 임포트 폴더: data/imports/에 박은 후 [ 새로고침]
  • 덮어쓰기 모드: 중복 instagram_id 발견 시 누적데이터(차수/히스토리)는 보존하고 메타 필드만 갱신

2. 마스터 표

  • 5,000명 페이지네이션 + 검색 (인스타ID / 셀러명)
  • 상태 필터 (미발송/발송중/답장받음/컨펌/거절/비공개)
  • 클릭 = 상태 변경 인라인

기기 및 계정 관리

  • 기기별 그룹 자동 정렬 (예: 갤럭시1 / 아이폰3 ...)
  • 회신율 컬럼 — 발송 대비 답장률 (녹색=10%+, 주황=3%+, 회색=3%-)
  • 회신율 높은 계정 = "황금 계정" → 중요 셀러한테 우선 사용
  • 회신율 낮은 계정 = 워밍업 부족 or 차단 위험 → 휴식 처리
  • 상태: 활성 / 사람인증 / 휴식 / 차단 — 비활성 계정은 큐에서 자동 제외

회신 인플루언서 현황

인라인 편집

대부분 컬럼은 자동 채워지지만, 수동 입력 필드가 있습니다 — 셀 클릭하면 노란색 → 다른 곳 클릭하면 자동 저장.

  • 자동 (시스템이 채움): No / 첫회신일 / 인스타ID / 회신계정 / 연결기기
  • 수동 (직접 입력): 상황 / 담당자 / 셀러명 / 팔로워수 / 이메일 / 전화번호 / 카카오톡ID / 비고

액션 버튼

  • 💬 = 그 대화 thread로 바로 점프
  • 📅 = 미팅 날짜 박기 → 진행 예정 셀러로 자동 등록 + 캘린더 자동 추가
  • 🎯 = 진행 예정으로 직접 이동 (미팅 없이)

자동 단계 전이

  • 상황 = 회신중/dm 소통중/카톡 소통중 → 진행 예정으로 자동 이동
  • 상황 = 미팅 fix → 미팅 예약으로 자동 이동
  • 상황 = 컨펌 → 캠페인 진행 중으로 자동 이동

진행 예정 셀러

단계 (Pipeline Stage)

  1. 진행 예정 — 답장 받은 직후
  2. 미팅 예약 — 미팅 날짜 박힌 상태
  3. 미팅 완료 — 미팅 후 결과 정리 중
  4. 캠페인 진행 중 — 캠페인 v2에 박힘
  5. 종료 — 완료 or 이탈

액션 버튼

  • 📅 = 미팅 추가 (날짜 + 메모) → 캘린더 자동
  • 📣 = 캠페인 v2 자동 생성 (1차 세트 + 광고 자동 박힘)

셀러명 클릭 = 디테일 모달

  • 연락처 한 화면 (이메일/전화/카톡/회신계정/첫회신일/차수/비고)
  • 미팅 기록 — 각 미팅 카드 안에서:
    • 날짜 / 결과 / 메모 / 녹취록 (직접 입력 + 자동 분석 예정)
    • 🎙 = 녹취 파일 (m4a/mp3/wav) 업로드
    • 💾 = 저장 / 🗑 = 삭제

셀러 캠페인 — 메타 광고관리자 스타일

계층 구조

캠페인 → 세트(차수) → 공동구매(광고)

  • 캠페인 — 셀러 + 브랜드 + 제품 (메가/마이크로/벤더 타입)
  • 세트 — 1차, 2차, 3차... 공구 차수
  • 공동구매 — 실제 작업 단위

공동구매 디테일 — 6섹션

  • 📦 제품 발송: 마지막 발송일 박기 → 캘린더 자동
  • 📅 스케줄링: 시작/종료 + 세부 일정 → 모두 캘린더 자동
  • 🎁 이벤트: 이벤트 리스트 (1+1 / 추첨 등) 자유 입력
  • 🔗 셀러 전달용 자료: 구글 드라이브 URL + 라벨 (라벨="제품 사진" 등)
  • 🖼️ 배너 (오픈피드/가격/이벤트): 체크 + 기획안 URL + 최종 이미지 URL + 메모
  • 🎬 릴스: 기획안 + 영상 URL + 상태 (기획중/제작중/검수중/완료)

콘텐츠 가이드 (스토리 자동 생성)

광고(마켓) 디테일 안 콘텐츠 가이드 = 셀러한테 보낼 일자별 스토리 제안.

  • 생성/재생성: 제품 정보 + 소구점(한 줄에 하나) + 글 길이 입력 → 생성. 자동 X, 반드시 입력 후 생성.
  • 셀러 말투 학습: 연결된 셀러 인스타 핸들 기준. 셀러 아카이브에 그 셀러 콘텐츠가 있으면 실제 올렸던 글의 말투/이모지 습관을 학습해서 복붙 가능한 퀄리티로 생성.
  • D-10 ~ D-day ~ D+N, 각 날짜 STORY 1~5 + 피드. 단계(도입→교감→정보→임박→마감) 자동 흐름.
  • 이미지: URL 직접 입력 X. 이미지 박스 클릭 → 셀러 아카이브에서 선택 (자동 추천 + 변경).
  • 셀러 링크: 모바일 최적화 공유 링크 복사 → 셀러한테 카톡으로 전달.
  • 미리보기 / 복사: 셀러 시트 새 탭 / 텍스트 복사.

셀러 모바일 뷰 (공유 링크)

셀러가 셀러 링크를 폰에서 열면:

  • 날짜 카드 리스트 → 탭하면 풀스크린 스토리 뷰어
  • STORY 1~5 + 피드 스와이프 (좌우 탭/스와이프)
  • 각 스토리: 소구점/제목 + 멘트 + 레퍼런스 이미지 + 복사하기 버튼
  • 체크리스트: 올리면 체크 → 우리 화면에 실시간 반영 + 진행률 바
  • (선택) 올린 스토리 링크 붙여넣기 → 우리가 라이브 클릭해서 확인
톤 학습 + 이미지
셀러 말투 학습 + 레퍼런스 이미지는 셀러 아카이브에 데이터가 있어야 정확함. [콘텐츠 도구 → 셀러 아카이브]에서 셀러 콘텐츠를 먼저 긁어오세요 (사용자 PC + 인스타 로그인 필요). 아카이브 없으면 generic 톤 + 이미지 없이 생성됩니다.

캘린더 (홈)

모든 데이터의 시간축 통합. 캘린더에 자동으로 들어오는 항목:

  • 미팅 — 회신 현황/진행 예정에서 박은 미팅
  • 마켓 시작 — 캠페인의 마켓 일정 (YYYY-MM-DD 형식)
  • 라이브 기간 — 공동구매 스케줄링 시작~종료
  • 세부 일정 — 공동구매 스케줄링 items 각각
  • 제품 발송 — 공동구매 제품 발송일

캠페인 데이터를 수정하면 자동으로 옛 이벤트 dedup 후 재생성 → 항상 최신 상태 유지.

자주 묻는 질문

발송이 안 되는데요?

클라우드(Render)에선 Playwright 브라우저를 못 띄워서 발송 불가. 사용자 PC(http://127.0.0.1:5000)에서 실행해야 함.

엑셀 임포트 후 데이터가 안 보여요

① data/imports/ 폴더 위치 확인. ② 엑셀 헤더가 양식과 매칭되는지 확인 (한글/영문 자동 매핑). ③ 인스타ID가 빈 행은 자동 skip.

덮어쓰기 모드는 뭘 보존하나요?

누적 데이터(발송 차수, 히스토리, 사용된 계정 리스트, 누적 발송수)는 그대로 유지. 메타 필드(셀러명, 상태, 비고, URL)만 새 값으로 덮어씀.

같은 셀러한테 다른 계정으로 또 보낼 수 있나요?

네. 단 마지막 발송 후 7일 지나야 함. 자동으로 다른 계정 선택 (used_account_ids 누적 추적).

회신율이 낮은 계정은 어떻게 처리?

3% 미만 = 회색 표시. 휴식 처리 권장 (큐 자동 제외). 워밍업 부족 또는 차단 위험 신호일 수 있음.

미팅 녹취 파일은 어디 저장?

진행 예정 셀러 디테일 → 미팅 카드 → 클릭 → m4a/mp3/wav 업로드 → data/meetings/ 에 저장. 자동 분석은 추후 Gemini 연동 예정.

다른 PC에서 작업 이어갈 수 있나요?

현재 — Git push/pull 통해 동기화. Phase H에서 Google Drive 자동 sync 박을 예정 (hwansnim@gmail.com).
